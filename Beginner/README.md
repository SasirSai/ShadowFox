# Boston House Price Prediction

This project aims to predict the median value of owner-occupied homes in Boston using various socioeconomic and structural factors from the provided Boston Housing dataset. It demonstrates a complete machine learning workflow including data preprocessing, rigorous model selection, hyperparameter tuning, and data visualization.

## 📁 Project Structure

The project has been intentionally decoupled into two separate scripts to separate the heavy computational machine learning logic from the visualization generation.

- **`HousingData.csv`**: The original dataset containing features like crime rate (`CRIM`), number of rooms (`RM`), age of property (`AGE`), and the target variable median value (`MEDV`).
- **`house_price_prediction.py`**: The core machine learning script. It handles data imputation, scaling, trains multiple models (Linear Regression, Random Forest, Gradient Boosting), fine-tunes the best model, evaluates the exhaustive metrics, and exports the results to a CSV file.
- **`visualizations.py`**: A completely standalone visualization script. It reads the exported predictions and generates analytical graphs without needing to retrain the ML model.
- **`predictions.csv`**: A lightweight CSV file automatically generated by `house_price_prediction.py`. It serves as the data bridge containing the actual and predicted house prices for visualization.
- **`actual_vs_predicted.png` / `residuals_distribution.png`**: Analytical plots generated by the visualization script.

## 🚀 How to Run

### Step 1: Train the Model and Generate Predictions
Run the main machine learning script first. This will clean the data, train the Gradient Boosting model, output detailed analytics (like MAPE, RMSE, and Feature Importances) to the console, and quietly save `predictions.csv`.

```bash
python house_price_prediction.py
```

### Step 2: Generate Visualizations
Once the predictions are saved, you can generate or refresh the analytical charts at any time by running the visualization script.

```bash
python visualizations.py
```
This will output `actual_vs_predicted.png` and `residuals_distribution.png` in the same folder.

## 📊 Evaluation & Metrics
The final tuned model (Gradient Boosting) was thoroughly evaluated and achieves high precision (capturing ~90% of the variance in prices), evaluated via:
- **RMSE & MAE**: For standard absolute error bounds.
- **MAPE**: For percentage-based error interpretation (averaging ~10% error).
- **Explained Variance & R2 Score**: To verify the model's robustness and fit.
